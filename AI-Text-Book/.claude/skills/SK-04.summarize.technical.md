# SK-04: Technical Summarization

## Description
Summarize technical content in clear and concise language. Distills complex technical material into digestible summaries while preserving accuracy and key information.

## Usage Example
```
/skill run SK-04.summarize.technical
Input: Technical document, research paper, or detailed explanation
Output: Clear, concise summary with key points highlighted
```

## Key Capabilities
- Extract key technical concepts and findings
- Simplify complex explanations
- Preserve technical accuracy
- Highlight practical implications
