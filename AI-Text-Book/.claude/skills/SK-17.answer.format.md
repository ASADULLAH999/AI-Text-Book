# SK-17: Answer Formatting

## Description
Format generated answers in structured and readable format. Organizes RAG-generated responses with citations, sections, and visual hierarchy for clarity and professional presentation.

## Usage Example
```
/skill run SK-17.answer.format
Input: Generated answer and context chunks
Output: Formatted answer with citations and structure
```

## Key Capabilities
- Organize answers with clear sections
- Add citations and source references
- Format for readability and accessibility
- Support multiple output formats
