# SK-18: Context Reranking

## Description
Rerank context chunks for better relevance in answers. Uses sophisticated algorithms to reorder retrieved chunks, improving the quality of context used for generating answers in RAG systems.

## Usage Example
```
/skill run SK-18.context.rerank
Input: Retrieved chunks and query
Output: Reranked chunks ordered by relevance
```

## Key Capabilities
- Apply reranking algorithms to chunks
- Calculate relevance scores
- Optimize context for answer generation
- Support custom reranking strategies
