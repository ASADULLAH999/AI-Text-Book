# SK-19: Task Tracking

## Description
Track tasks, status, and deadlines in the project workflow. Maintains a todo list for textbook chapters, RAG development, and project milestones with progress visualization.

## Usage Example
```
/skill run SK-19.task.track
Input: Task title, status, and deadline
Output: Updated task list with progress tracking
```

## Key Capabilities
- Create and manage task lists
- Track task status and progress
- Set and monitor deadlines
- Generate progress reports
