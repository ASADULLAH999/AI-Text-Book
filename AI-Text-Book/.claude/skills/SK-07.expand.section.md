# SK-07: Section Expansion

## Description
Expand sections with detailed explanations, examples, and supporting information. Enriches existing content with deeper context, illustrations, and practical applications.

## Usage Example
```
/skill run SK-07.expand.section
Input: Section title or outline
Output: Expanded section with detailed explanations and examples
```

## Key Capabilities
- Add detailed explanations to concepts
- Include relevant examples and case studies
- Provide practical applications
- Expand with supporting evidence and citations
