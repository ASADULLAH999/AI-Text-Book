# SK-21: Checklist Generation

## Description
Generate checklists for content review, quality assurance, and project milestones. Creates structured checklists to ensure all requirements, quality standards, and completion criteria are met.

## Usage Example
```
/skill run SK-21.checklist.generate
Input: Project phase or content type
Output: Structured checklist with verification items
```

## Key Capabilities
- Create content review checklists
- Generate quality assurance checklists
- Define milestone verification criteria
- Support custom checklist templates
