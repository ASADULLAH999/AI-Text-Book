# SK-09: Fact Verification

## Description
Verify facts and ensure accuracy of information. Cross-references claims against reliable sources and identifies potential errors, outdated information, or unsupported assertions.

## Usage Example
```
/skill run SK-09.fact.verify
Input: Text or claims to verify
Output: Verification results with sources and corrections
```

## Key Capabilities
- Validate factual claims against sources
- Identify outdated or incorrect information
- Flag unsupported assertions
- Provide corrected information with citations
