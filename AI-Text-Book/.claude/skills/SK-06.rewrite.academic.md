# SK-06: Academic Rewriting

## Description
Rewrite text to meet academic standards and maintain formal tone. Ensures content adheres to scholarly conventions, proper terminology, and professional presentation standards.

## Usage Example
```
/skill run SK-06.rewrite.academic
Input: Informal or non-academic text
Output: Text rewritten in academic style and formal tone
```

## Key Capabilities
- Convert to formal academic tone
- Apply scholarly conventions
- Use precise technical terminology
- Ensure appropriate register and voice
