# SK-13: Text Embedding

## Description
Embed text into vector databases for retrieval and AI processing. Converts textual content into vector embeddings suitable for semantic search, similarity matching, and RAG systems.

## Usage Example
```
/skill run SK-13.embed.text
Input: Text content to embed
Output: Vector embeddings stored in vector database
```

## Key Capabilities
- Generate vector embeddings from text
- Store embeddings in vector database
- Support multiple embedding models
- Handle batch processing for large documents
