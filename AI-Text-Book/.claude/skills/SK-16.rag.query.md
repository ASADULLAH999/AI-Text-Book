# SK-16: RAG Query

## Description
Query the RAG (Retrieval-Augmented Generation) system for answers. Retrieves relevant context from your vector database and generates informed responses based on your textbook content.

## Usage Example
```
/skill run SK-16.rag.query
Input: User question or query
Output: Retrieved context and generated answer from RAG system
```

## Key Capabilities
- Search vector database for relevant content
- Retrieve top-k most similar chunks
- Generate answers grounded in retrieved context
- Support multi-turn conversations
