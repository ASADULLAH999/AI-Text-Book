# SK-20: Plan Generation

## Description
Generate project plans and timelines from specifications. Creates detailed project schedules, milestone definitions, and dependency maps to guide textbook and RAG system development.

## Usage Example
```
/skill run SK-20.plan.generate
Input: Project specifications and requirements
Output: Project plan with timeline, milestones, and dependencies
```

## Key Capabilities
- Create project timelines and schedules
- Define milestones and deliverables
- Identify dependencies and critical paths
- Generate Gantt charts and roadmaps
