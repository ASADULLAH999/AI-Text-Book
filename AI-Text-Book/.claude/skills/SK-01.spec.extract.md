# SK-01: Specification Extraction

## Description
Extract specifications and requirements from project documents, research papers, and technical materials. This skill identifies key requirements, constraints, dependencies, and acceptance criteria from unstructured or semi-structured documents.

## Usage Example
```
/skill run SK-01.spec.extract
Input: Project proposal or requirements document
Output: Structured specifications with requirements, constraints, and acceptance criteria
```

## Key Capabilities
- Parse technical specifications and requirements
- Identify constraints and dependencies
- Extract acceptance criteria
- Organize requirements by priority and scope
