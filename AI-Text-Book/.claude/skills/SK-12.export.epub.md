# SK-12: EPUB Export

## Description
Export content as EPUB eBooks for reading devices. Creates e-reader compatible formats optimized for tablets, e-readers, and digital publishing platforms.

## Usage Example
```
/skill run SK-12.export.epub
Input: Document content and metadata
Output: EPUB file for e-readers and digital platforms
```

## Key Capabilities
- Generate EPUB format files
- Optimize for e-reader devices
- Include metadata and table of contents
- Support reflowable and fixed layouts
