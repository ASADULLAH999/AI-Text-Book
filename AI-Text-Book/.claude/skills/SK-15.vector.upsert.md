# SK-15: Vector Upsert

## Description
Insert or update vectors in your vector database. Manages vector storage operations including creation, updates, and retrieval of embeddings in Qdrant or similar vector stores.

## Usage Example
```
/skill run SK-15.vector.upsert
Input: Vector embeddings and metadata
Output: Confirmed storage in vector database
```

## Key Capabilities
- Insert new vectors into database
- Update existing vector entries
- Manage vector metadata and collections
- Handle batch upsert operations
