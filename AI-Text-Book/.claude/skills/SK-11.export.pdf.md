# SK-11: PDF Export

## Description
Export documents or reports as PDF files. Converts text, formatted content, and structured documents into professional PDF format suitable for distribution and printing.

## Usage Example
```
/skill run SK-11.export.pdf
Input: Document content and formatting options
Output: PDF file ready for download or distribution
```

## Key Capabilities
- Convert documents to PDF format
- Preserve formatting and layouts
- Include headers, footers, and page numbers
- Support for embedded images and diagrams
