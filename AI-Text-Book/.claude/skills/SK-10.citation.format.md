# SK-10: Citation Formatting

## Description
Format citations in required academic styles (APA, MLA, Chicago, Harvard, etc.). Converts reference information into properly formatted citations for academic papers and publications.

## Usage Example
```
/skill run SK-10.citation.format
Input: Reference information and desired format (APA, MLA, etc.)
Output: Properly formatted citations
```

## Key Capabilities
- Format in multiple citation styles (APA, MLA, Chicago, Harvard)
- Handle various source types (books, articles, websites, etc.)
- Create bibliographies and reference lists
- Validate citation completeness
