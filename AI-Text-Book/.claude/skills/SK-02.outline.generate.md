# SK-02: Outline Generation

## Description
Generate structured outlines for tasks, chapters, reports, and projects. Creates hierarchical outlines with clear sections, subsections, and logical progression to guide writing and organization.

## Usage Example
```
/skill run SK-02.outline.generate
Input: Topic or chapter title
Output: Multi-level structured outline with sections and subsections
```

## Key Capabilities
- Create hierarchical outlines for chapters and sections
- Define learning progression and prerequisites
- Organize content by complexity level
- Map dependencies between sections
