# SK-08: Diagram Generation

## Description
Generate diagrams from specifications or structured outlines. Creates visual representations including flowcharts, architecture diagrams, and concept maps from text-based specifications.

## Usage Example
```
/skill run SK-08.diagram.generate_spec
Input: Specification or outline structure
Output: Generated diagram (Mermaid, ASCII art, or description)
```

## Key Capabilities
- Create flowcharts and process diagrams
- Generate architecture and system diagrams
- Produce concept maps and relationships
- Support multiple diagram formats
