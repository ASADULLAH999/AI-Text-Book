# SK-14: Chunk Optimization

## Description
Split large documents into optimized chunks for processing. Segments content into logical, semantically meaningful chunks with appropriate overlap for better retrieval in RAG systems.

## Usage Example
```
/skill run SK-14.chunk.optimize
Input: Large document content
Output: Optimized chunks with metadata and boundaries
```

## Key Capabilities
- Split documents into semantic chunks
- Maintain context with overlapping segments
- Preserve sentence and paragraph boundaries
- Calculate chunk statistics and metadata
