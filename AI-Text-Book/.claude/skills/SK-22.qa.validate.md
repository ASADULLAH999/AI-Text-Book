# SK-22: Quality Assurance Validation

## Description
Validate content quality and ensure accuracy standards across the textbook and RAG system. Performs comprehensive quality checks including consistency, completeness, and accuracy of technical content.

## Usage Example
```
/skill run SK-22.qa.validate
Input: Content chapter or RAG component
Output: Validation report with quality metrics and recommendations
```

## Key Capabilities
- Validate technical accuracy
- Check content consistency and coherence
- Verify completeness of sections
- Generate quality metrics and reports
