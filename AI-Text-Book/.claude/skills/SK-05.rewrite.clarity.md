# SK-05: Clarity Rewriting

## Description
Rewrite text to improve clarity and readability. Enhances comprehension by simplifying language, improving sentence structure, and removing ambiguity while maintaining original meaning.

## Usage Example
```
/skill run SK-05.rewrite.clarity
Input: Original text or content passage
Output: Rewritten text with improved clarity and flow
```

## Key Capabilities
- Simplify complex sentences
- Improve paragraph structure and flow
- Remove jargon and ambiguous language
- Enhance readability for target audience
